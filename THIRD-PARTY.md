## Maia networks

`maia/maia-1100.bin`, `maia-1500.bin` and `maia-1900.bin` are converted from the Maia chess networks by the Computational Social Science Lab (McIlroy-Young, Sen, Kleinberg, Anderson), https://github.com/CSSLab/maia-chess, GNU GPL v3. The originals are in `tools/data/maia-*.pb.gz`; `tools/convert-maia.mjs` folds batch normalisation into the convolutions and stores the weights as half floats. `maia/tables.json` holds Leela Chess Zero's policy index and convolution policy map (https://github.com/LeelaChessZero/lc0, GNU GPL v3), from `tools/data/lc0-policy-index.py` and `tools/data/lc0-policy-map.h`. The inference code in `src/maia-core.js` is this project's own implementation of the Leela network format.

## Positions

- **Starter set.** Original composed positions and moves from historical miniature games, with colour-reflected variants generated by this project. Titles are teaching labels rather than detailed historical citations.
- **Generated puzzles.** Mined by this project from Stockfish self-play games (`tools/generate-puzzles.mjs`) and checked with Stockfish. Their ratings are estimates.
- **Lichess puzzles (optional).** If you run `tools/import-lichess.mjs`, puzzles come from the Lichess puzzle database, released under CC0 1.0: https://database.lichess.org/#puzzles. Attribution is not required, but thanks to Lichess and its players.

## Development-only tools

Playwright (Apache-2.0) runs the browser tests. It is not part of the published site.

Fetching games uses the public Lichess API (https://lichess.org/api) and the Chess.com Published-Data API (https://www.chess.com/news/view/published-data-api), only when the user asks.
